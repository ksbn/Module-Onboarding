## 🧠 Questions and Answers

### What is the purpose of a README file?
A README file helps others understand what your project does, how to install and use it, and how to contribute.

### What is the purpose of a wireframe?
A wireframe is a simple layout of a website or app that shows the structure of content and interface elements before detailed design and coding.

### What is a branch in Git?
A branch is a separate version of the codebase where you can work on new features or fixes safely, then merge it into `main` when ready.
